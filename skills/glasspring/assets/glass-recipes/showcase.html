glasspring — glass recipe showcase

Test fixture N3 · tiers 1/2/3 + worst-case contrast + spring curve (scripts/spring_convert.py). Backdrop stripes simulate worst-case bright content scrolling under glass.

Tier 1 · Full Glass

backdrop-filter: blur(20px) saturate(180%) + 0.72 tint alpha floor. Text must stay ≥4.5:1 against the worst-case backdrop — see the contrast row below.

Tier 1 garnish · Liquid edge

Optional decoration from glass.md §1: conic-gradient border light + top/bottom speculars fakes refraction with plain paint. Decoration only — removing it loses no information (same rule as Tier 3).

Tier 2 · Opaque Scrim

Ships automatically via @supports not (backdrop-filter…), reduced-transparency, forced-colors, and low-device heuristics. No blur needed to be readable.

Tier 3 · Refraction (gated — plain blur shown here)

SVG feDisplacementMap edge bending on top of Tier 1 — applied only behind a feature detect + device gate. See refraction-experiment.html. Tested: data-URI feImage can hang embedded Chromium webviews, so the main fixture never depends on it. Decorative only.

Dark glass · worst-case backdrop = white/yellow bands

Tint rgba(18,20,28,0.72) over pure white → effective bg ≈ #54565C; white text ≈ 7.3:1 (AAA). Verified with check_contrast.py --composites.

FAIL ON PURPOSE — teaching case

White text on 0.18-alpha glass over yellow. ≈1.4:1 — never ship. Raise tint alpha to ≥0.70 or switch text color.

PASS — 0.72 tint floor

Dark text on 0.72 white tint over the same yellow → effective bg ≈ #FFF3B8, ≈16.5:1. This is the tint-alpha floor rule from glass.md.
