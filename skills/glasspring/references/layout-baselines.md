# layout-baselines.md — 落地页/营销页量化基线（构图/色彩/字型/动效/图像）

> When to read: landing/marketing/portfolio 类页面的**构图阶段**（Step 4 落地页分支）。
> **部分来源核验（2026-10-26）：** Taste Skill 的量化资料固定在 [commit 6010f91](https://github.com/Leonxlnx/taste-skill/tree/6010f91a9935f1c167dfc500fb1a475681892e6b)，对应 [研究方法](https://github.com/Leonxlnx/taste-skill/blob/6010f91a9935f1c167dfc500fb1a475681892e6b/skills/taste-skill/references/research.md#L19-L39) 与 [布局观察](https://github.com/Leonxlnx/taste-skill/blob/6010f91a9935f1c167dfc500fb1a475681892e6b/skills/taste-skill/references/layout.md#L1-L35)。首组研究收集 248 个站点、247 个加载成功、246 个重新测量；21 名模型评审根据截图和页面测量评分，235 个样本可供评审。114 个 7.3+ 样本的“约”计数来自评审笔记。一次采样、画廊选样和模型评分带来明显边界；组间差异是描述性关联，不证明某个样式导致更高质量，也不代表真实访客偏好。
> 10 月 Sites of the Day 观察是另一组研究，各分析使用的可用样本数可能不同；不要混用分母。此卡也引用其他来源；未逐项标明的出处、许可和改写仍待审，见仓库级第三方审查。下文的禁用项和风格偏好是 Glasspring 的项目规则，不是普遍设计定律。

## 强页的量化习惯（114 个 7.3+ 站手工计数）

- **边距紧、内容到边**：约 45/114 用 ≤32px 外边距；仅 ~8 用 ≥80px。居中 1100–1300px 容器在高分站是**少数派**——那是"stock 脸"的常服。
- **锚线纪律**：约 22/114 把文字锚在一条**非中心非边缘的固定线**上（1/3 处、42%、中点）。**全页两三条锚线；六条 = 什么都没决定**。
- **两三个字号，中间nothing**（约 30 站）：一个特大配一个特小，或把字号额度全让给图像。
- **一屏一事**（约 20）：一个陈述、一个物件、一个项目。
- **分段靠底色**：约 20 站逐段换整段背景色；约 12 亮暗交替；约 10 永不变、纯靠留白。
- **段落重排而非重复**（约 14）：每段重新构图；约 12 交替"满血图像屏 × 近空文字屏"。
- **系统被故意打破一次**（约 14）：分裂页上的一行居中、暗页上的一张纸卡、压到最后才出现的颜色。
- **常无导航条**（约 45）；结尾是设计过的场景而非链接列。
- **词少**：全研究词数中位 **575**；最好的站低于 200。

## CSS 起手

```css
:root {
  --margin: clamp(1rem, 2.2vw, 2rem);   /* 16–32px：紧，让内容到边 */
  --gutter: clamp(0.75rem, 1.4vw, 1.5rem);
}
.wrap { padding-inline: var(--margin); }
.grid { display: grid; grid-template-columns: repeat(12, minmax(0, 1fr)); column-gap: var(--gutter); }
```

- 全页一对边距、一套网格；**别反射式套 `max-width:1200px; margin:auto` 容器**——大件（字/图/色场）跑满宽，只约束行文测宽（`ch` 加在段落上不在页面上）；超宽屏 ~1760–1920px 封顶或 vw 字号用 clamp 封顶。
- **永远不要画出网格**：列线/十字准星/参考线在此是被禁的时髦装饰——网格靠对齐被感知。

## 文字放哪

- 选中锚线并复用：hero 大标题从第 5 列起，段标题、价格数字、页脚链接也从那里起。
- **偏心胜居中**：左 1/3 标题 + 远右列同行基线段落、中間什么都没有；下 1/3 标题压着一片**有意的虚空**；文字泊在角上，中间让给图。
- 对角式：同一基线两端各一小段文字（名字左、一行描述右）是居中堆叠的常见替代。
- **内容优先屏**（oil-ui 2026-10-24）：浏览/工作页以**内容本身为首屏**（工具先展示工具，商店先展示商品）——只有说服型页面（landing/品牌）才配设计型开场；工作页做设计型开场=把用户当访客
- **记忆时刻**（同源 "Leave one moment people remember"）：每页留 1-2 个**微记忆点**（一次点按反馈/一个支付成功态/一页 404）而其余保持安静——打破一次律的微观形态：break 不限于色，可以是一个交互的瞬间
- **居中是一种决定**：真要居中就用单轴 + 两侧宽空 + 每屏一个元素，而非"标题+段落+双按钮"居中堆叠。
- **左文右图 hero = 最滥用的 AI 构图**（imagegen-frontend-web 2026-10-22 新源首条）：能用替代就用替代——左下压图/居中堆叠/离格编辑式/图作画布；确属最优才可用并在 design-notes 陈述为何
- **hero 三禁**（gpt-taste 交叉 2026-10-22）：①悬浮印章/徽章图标（floating stamp/badge）②hero 下 pill 标签排③hero 裸数据（raw stats）——hero 只留一句陈述+一个动作；数据进证据区不进 hero
- **词间嵌图**（stitch-design-taste 签名技法 2026-10-22）：小尺寸语境图直接嵌进标题词与词之间（inline image typography）——display 字排的一个高辨识变奏，题材有强视觉物件时首选（咖啡豆嵌进"豆"、车头灯嵌进"灯"）
- **broadsheet 组合 tell**（官方 frontend-design 2026-10-22 校准组③）：发丝线分栏+全站零圆角的「报纸排演」是印刷 cosplay——真印刷语法属 editorial-magazine（衬线+首字下沉+真网格节奏），零圆角属 brutalist（2-3px 粗黑边）——**两个语法各归其派，杂交出 tell**
- 长文行：标题左 1/3、正文右 2/3，全页同一分割。

## 空白：rest 与 hole

空白是**放出来的**，不是剩下来的。大块空地要么是 rest（有别的东西把它合上），要么是 hole（没有任何东西合上它——访客点名批评的就是 hole："大块随机空白"）。强站 rest 很多，且约一半仍会留至少一个 hole——留 hole 必须是故意的。

## 分段与导航

- 每段**携带想法、变化排布**：同一想法每段换构图；不要复制同一段式样。
- 导航退后或不存在；**结尾设计成场景**（一句收束 + 一个动作），不是三列链接。

## 如何失败（反面清单）

居中堆叠容器 + 均匀段落复制 + 处处画出的网格 + 六条以上锚线 + 剩出来的空白 + 链接列结尾——以上任意两条同时出现，页面就回到 stock 脸。


## 色彩实测（colour.md）

- 41% 暗 / 59% 亮；配色分布：单色+一强调 23%、亮中性 22%、暗中性 14%……
- **按钮中性色（黑白灰）占 52%**——彩色按钮是一种选择，不是义务。（FM-6：风格包内有相反律时包法胜——warm-soft-saas「按钮必须有色」、swiss 红标点等包内正典不适用本条）
- **渐变填充：高分站 22% vs 弱站 52%；渐变字：2% vs 13%**——梯度是弱站信号。**官方 cookbook 的「分层背景」不翻案**（2026-10-22 仲裁）：cookbook 反的是"平涂实底默认"，开的是**氛围分层**（颗粒/几何线纹/0.03 光斑——minimalist-ui 深度律同族），不是彩色渐变色场； FM-6：画廊实证（弱站信号）> 官方修辞，装饰性彩色渐变维持禁止
- **246 站仅 1 站赤陶主按钮、零站紫主按钮**——"那些是生成页的颜色，不是画廊的颜色"（glasspring slop 色的最强实证）；暖米白底常见（32 站）但几乎总配深墨或绿墨而非橙强调。
- **icon 特征卡行：强站 1% vs 弱站 28%**（taste-skill house rules 2026-10-22，与 23 屏「KPI 即文字非磁贴」互证的最强单条）——"图标置顶+题+文"三连卡是 AI 页的第一结构 tell；能力点用段落重排/变宽列承载
- **节序模板库**（ui-ux-pro-max landing.csv 34 模式深读 2026-10-24）：落地页=**节序（Section Order）× CTA 布点（Placement）× 转化注记**三维编码——模板是起点速查不是终点（34 模式全均可被题材引擎重排）；采样：漏斗式=三步问题→方案→行动 + 每步微 CTA + 进度指示；定价页=价格卡 + 特性对照表 + FAQ + 终 CTA + 月/年切换动画；**Mini 单列**=收益要点 ≤3 + 无导航杂讯（与我方「词少/一屏一事」同族）
- **空箱并集测量**（XIAS verify_screen_economy.mjs 深读 2026-10-24）：hollow = **未用空间非低墨量**——箱式件（边框或底色+圆角+内距、超视口份额阈）取全部可见子元素与文本节点的**并集包围盒 ÷ 内域面积**；低于密度阈=空箱（1494px 卡片配三短行=7% 不过）；**气排印不算空**（墨水覆盖率版曾 30% 误杀）——void-rest/hole 律的机械测法
- **首屏自证**（同源，390×844 手机视口）：首屏必须有**可读 h1**（visually-hidden 不算——首跑即抓到 checkout 页 sr-only h1 空洞）+ **可见动作钮/链接**；`data-harness` 演示页与 aria-busy 页豁免
- **状态色移谱律**（meodai colorandcontrast/color-effects 深读 2026-10-24）：组件状态切换的大幅色相跳变触发**连续对比**（successive contrast——前视色改变后视色感知，色适应残像所致）→ 状态切换保持在**邻近色相/同相明度档内**（hover 提亮不换相）；极端情况致可读性问题甚至偏头痛；**同时对比不可依赖**（部分用户对某些色不体验该效应——"Do not rely on simultaneous contrast as a mechanism for distinguishing UI elements"）；暗视觉 Purkinje（感光峰移蓝，红变暗）为暗模式红系降档的感知根据
- **理论包袱律**（meodai itten-seven-contrasts-critical-review 深读 2026-10-24）：经典色彩对比理论（Itten 七对比）经实证批评**大部分不成立**——色相对比/明暗对比「非对比，只是属性」；互补对比混淆颜料混色与感知效应；饱和对比的插图被实测自证失败（黄「实测亮于对应灰」与其等明度声明矛盾）；**单对色可同时呈现全部七对比**=作为分析范畴无效；教学实证：Itten 基教学五年研究「师生皆不满」。工程含义：**不引用经典色彩理论名词作为设计依据**（互补/冷暖/面积对比）——设计依据=可实测属性（OKLCH 数值/对比度/ΔE）；"don't look for color contrast, go to the museums and enjoy"
- **着色器渐变= mix+塑形**（meodai book-of-shaders 深读 2026-10-24）：程序化色彩的地基是 `mix(a,b,pct)` + **塑形函数**（pct 经 easing 非线性化——渐变的「手感」全在塑形不在 mix）；极坐标色轮=角度→色相/半径→饱和度（GLSL 标准法）；RYB 色轮=对色相**扩张特定区间**的塑形（与 RYBitten/harveyHue 同源）——Web 侧注脚：CSS 渐变无塑形钩子，等效手感靠多段补点（渐变分段律）或 scroll-driven
- **奢侈品色定量**（meodai brand-color-luxury-positioning 深读 2026-10-24）：luxury 中性场的 **OKLCH chroma ≈0.01–0.03**（Rolex 深绿+金/Hermès 焦橙+暖中性/Cartier 黑奶油酒红）；差异变量**不是色相而是比例与 chroma 控制**——奢侈=大面积低彩中性场+极少高彩点，折扣=满幅最高彩；**色多读作廉价**（信号竞争）；60-30-10 比例律；正文对比 APCA 75+（金上白常翻车——luxury 不能豁免对比门）；警示：色相→含义（蓝=信任）是弱主张，市场惯例解释优于感知定律
- **反默认蓝/靛双生产源**（Same.dev「avoid purple, indigo, or blue unless specified」+ Z.ai「NO indigo or blue」2026-10-23 双源独立立法）：默认蓝 #3B82F6 系与靛蓝在未点名时禁作主色——用户点名（brief-wins）或品牌即蓝才可用
- **assistant palette 立法**（同源）：黄奶油底配赤陶/铁锈**或**紫罗兰/靛蓝的整套配色是"助手脸"——slop 检查从单点色（cream+terracotta）升级为**配色组合**检查
- **accent 饱和上限**（stitch-design-taste 2026-10-22）："Maximum 1 accent color. Saturation below 80%"（HSL S 语境）——accent 数 ≤1 与饱和封顶双约束；OKLCH 域换算随色相浮动，实测门禁为准；纯黑禁用同源（Zinc-950/炭黑替代——与我 dark 档禁 #000 互证）
- 高分站更常**逐段换底色**（段底色中位 2 个 vs 1 个）。

## 动效预算（motion.md 55k）

- **静态页必须先过检**：动效是最后一道工序，**永远不是拯救弱布局的手段**。
- **预算制**：inspector 统计加载+滚动期间动起来的元素，**少于八个判失败**。五部分 = 2-3 个滚动大场面 + 1 个签名时刻 + 其余安静。

## 图像实测（imagery.md 51k）

- 60% 站的首屏有一块媒体占**至少一半**首屏（高分站 68%）；仅 15% 的 hero 无媒体（且是刻意的纯字声明）。
- **强站图多：中位 37 张 vs 弱站 5 张——"强站展示，弱站讲述"**。
- 媒体方角占 73%；圆角则统一 ~12px。

## 密度连续性（ux-ui design-taste Block Coherence，2026-10-20）

跨轮追加的块必须读作同一系统：同 token 同字阶同圆角语言、复用既有原语（不手搓平行 Button）、**变化构图而非变化词汇**（布局与上一块不同，材料恒定）、**密度连续**（air hero 后突接密表 = bolted-on）、态与 a11y 与暗色行为与相邻块同权。

## 域分野注记：全出血 hero 的两派（2026-10-20 仲裁）

**跨源哲学分叉如实记录**：ux-ui design-taste 的 Screen economy 房规**禁全出血 hero**（媒体封顶 60vh——"满屏图给读者的不是他们来要的东西"），而 scroll-craft/taste-skill 的实测（99 SOTD：68% 高分站首屏媒体占半屏以上，且**媒体占比与分数正相关**）支持全出血。**glasspring 裁决：按 Q1 域路由分治**——营销/作品页走实测支持的全出血文化（taste-skill 数据）；产品/工作面遵 economy 纪律（OLED 能耗/信息密度）。两派各自的数据基础不同：前者是房规无实测引用，后者是 99 站测量。若品牌规范点名 economy，X1 brief-wins 适用并在 design-notes 声明适配。

## 评审三过（taste-skill critique.md 14 过法的三把最利刀）

1. **边上计数**：沿每段文字的左缘下行，数全页不同的 x 起点——**2-3 个 = 有意的构图，6 个 = 逐件随手放的**。
2. **同段式检查**：给每段的布局起一个词（split/list/full-bleed/grid/statement/index…）——**同一个词连用两次或全页三次 = 模板在showing**。
3. **竞品+唯一活物**：把最近竞品的名字放到页面上——创意还成立吗？页面上访客能做的/每次来访不同的一件事是什么？两答皆弱 = 本轮第一问题，先于一切细节。

附：**贫瘠不是克制**——删掉装饰后，检查页面是否仍有足够的真实内容、层次和视觉重心。这是对上游模型评审反馈的有限改写，不推出“丰富总胜过克制”；评审样本、模型评审和复用 brief 的限制见 [研究记录](https://github.com/Leonxlnx/taste-skill/blob/6010f91a9935f1c167dfc500fb1a475681892e6b/skills/taste-skill/references/research.md#L248-L273)。删去的装饰需由 brief 真正需要的内容或结构补位。
