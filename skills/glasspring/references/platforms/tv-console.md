# platforms/tv-console.md — TV/主机平台适配器（10 英尺规则与手柄焦点）

> When to read: 交付物运行在电视/游戏主机大屏（Xbox/PlayPoint/智能 TV/机顶盒）——10 英尺外、手柄/遥控器操作、客厅环境。
> Source status: The historical source ledger is not included in this public preview. Treat this card as project design guidance, not independently verified or universally applicable research.

## 1. 10 英尺硬规则（数字即规格）

- 交互件 ≥32epx；正文 ≥15epx；辅助 ≥12epx（一切 ×2 于移动端量级）。
- 安全区：上下 27epx / 左右 48epx 内不放关键内容（TV 过扫描裁切）。
- 色彩：TV-safe 16-235——高饱和在电视上溢出发灰，深色渐变糊成一块；对比靠明度不靠色相。
- **≤6 击**（方向键）穿越屏到任何可达项；两列以上网格必须定义显式焦点链。
- 深色为默认（客厅暗光 + OLED 灼屏规避 + 沉浸感）。

## 2. 焦点引擎（XY 导航语法）

- 方向键只有四向：**布局必须二维可预测**（焦点框对齐网格；禁止列表横竖混排无显式顺序）。
- 焦点指示：放大（1.05-1.1 倍）+ 描边 + 阴影三通道；绝不只变文字颜色。
- 可聚焦元素尺寸（官方值，HIG Accessibility 2026-10-18）：tvOS 系统控件**默认 66×66pt、最低 56×56pt**——自绘焦点目标不小于 56pt。
- 焦点记忆：返回上一屏焦点回到原项（丢失焦点 = 用户迷路）。
- 按住/长按用手柄按键语义（X/Y/肩键），tooltip 进按键提示条（底部）。
- 红线：嵌套滚动区焦点陷阱；focus 进屏外元素；只用颜色标记选中。

## 3. 信息层级（10 英尺可读性）

- 一屏一个主任务（电视是"看"的媒体，输入成本极高）；文本精简到移动端的一半。
- 层级三档：焦点项（大+亮）/ 可选项（中）/ 背景项（暗+虚化）；键入（搜索/登录）进独立极简屏或手机配对。
- 图片优先于文字（海报/封面/预览视频）；文字只在确认类信息。
- 红线：TV 上要求文本输入不提供手机配对；多列瀑布流（焦点导航噩梦）。

## 4. 质量底线

- 手柄全流程无死路（每屏可返回/可达主页）；焦点从屏四边进入均可预测。
- 深色主题 + 环境光自适应亮度；OLED 灼屏规避（静态高亮元素定时微移）。
- 音效反馈（导航哔/确认咚）是 TV 端一等反馈通道（视觉焦点之外）。
