# Agent guidance for this repository

Design work in this repository should use the bundled Glasspring skill at
`skills/glasspring/SKILL.md` (Agent Skills format). For a project install:

```sh
node skills/glassspring/scripts/install.mjs --target <project> --host codex   # or --host claude
```

See [INSTALL.md](INSTALL.md) for host verification and removal, and
[README.md](README.md) for scope and evidence limits.
